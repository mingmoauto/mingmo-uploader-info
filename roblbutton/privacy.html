목적과 접근 범위

로블버튼 운영자가 사용하는 개인용 댓글 운영 도구입니다. Google OAuth로 동의를 받아 채널 ID, 공개 영상의 제목·설명·공개 여부, 댓글 ID·내용·작성자 채널 식별자·시각·기존 답글을 확인하고 답글을 게시합니다. 요청하는 youtube.force-ssl 권한은 Google 화면에 영상·댓글 관리 권한으로 표시될 수 있으나 이 도구의 기능은 댓글 조회·답글과 소유 채널 확인으로 제한합니다. Google 계정 비밀번호는 수집하지 않습니다.

처리와 보관

댓글 후보의 내용, 댓글 ID, 관련 영상 제목·설명 및 기존 답글 문구를 OpenAI API에 보내 답글을 작성합니다. Google 인증 토큰은 OpenAI에 전달하지 않습니다. API 요청은 store=false를 사용합니다. GitHub Actions에서 실행하며 인증 정보는 비공개 GitHub Secret에 저장합니다. 댓글 수집 자료, 중복 방지용 처리 이력, 답글 및 검증 결과는 운영자가 관리하는 비공개 저장소와 필요한 로컬 운영 기록에 보관합니다. 현재 조회 자료는 갱신되지만 버전 이력과 처리 원장은 운영·중복 방지에 필요한 동안 남을 수 있습니다.

공유와 제한된 사용

Google 사용자 데이터는 위 댓글 관리 기능을 제공하는 목적으로만 사용합니다. GitHub는 실행·보관, OpenAI는 답글 생성에 사용됩니다. 데이터를 판매하거나 광고 타기팅 및 범용 AI 모델 학습을 위해 사용하지 않습니다. Google API에서 받은 정보의 사용·다른 앱으로의 이전은 제한된 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. 게시된 답글은 YouTube에서 공개됩니다.

연결 해제와 삭제 요청

운영자는 Google 계정의 외부 앱 연결 관리에서 접근 권한을 철회하고 자동 작업을 중지할 수 있습니다. 저장된 인증 정보·처리 기록의 삭제는 로블버튼 채널 운영자에게 요청할 수 있습니다. 철회는 이미 게시한 YouTube 답글을 자동 삭제하지 않습니다. 이 도구는 시청자의 비밀번호나 별도 회원 가입을 요구하지 않습니다.
